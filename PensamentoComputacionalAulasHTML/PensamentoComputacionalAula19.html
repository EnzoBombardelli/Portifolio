Aula 19 - Turma A: Introdução ao JavaScript e Lógica de Programação

(Terça-feira, 29/09/2026 | 14h15 às 16h00)

Nessa aula do dia 29 de setembro, o instrutor Victor apresentou uma introdução à linguagem de programação JavaScript, responsável por definir a lógica e o comportamento das aplicações web. Para organizar o ambiente de desenvolvimento no Visual Studio Code, os alunos criaram a estrutura inicial do projeto composta pelos arquivos index.html, style.css e script.js. Em seguida, foram explicadas as ferramentas de inspeção dos navegadores, destacando a aba de elementos para visualização do código HTML e o console para execução de comandos. O instrutor detalhou a declaração de variáveis com let e const, abordando os tipos number, string e boolean, além do uso do comando console.log(). Com o intuito de aplicar esses conceitos, os estudantes realizaram quatro atividades práticas focadas em concatenação e operadores aritméticos, contando com o suporte da monitoria para esclarecer dúvidas e exercitar a criação de variáveis, o que permitiu à turma demonstrar facilidade ao transformar a teoria em código antes de realizar o envio dos projetos para o GitHub.
