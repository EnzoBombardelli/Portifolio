Aula 09 - Turma A: Tabelas em HTML

(Quarta-feira, 07/07/2026 | 14h15 às 16h00)

Nessa aula do dia 07, o instrutor Victor realizou uma revisão sobre formulários em HTML, apresentando novamente o código de aulas passadas para consolidar o uso de tags como <input>, checkbox e radio. Na sequência, foi introduzido o estudo de tabelas em HTML, abrangendo elementos como <table>, <tr>, <td> e <caption>, além de propriedades de CSS para a criação de bordas e melhoria visual das estruturas. Com o objetivo de transformar a teoria em prática, os alunos foram desafiados a criar uma tabela de horários escolares no Visual Studio Code, explorando atributos avançados como colspan e rowspan para a organização de linhas e colunas. Durante a atividade, foi oferecido suporte individualizado para resolver dúvidas técnicas e auxiliar na estilização do código. O encontro foi finalizado com o envio dos arquivos para os repositórios no GitHub e o repasse dos avisos finais antes do período de férias.
