Aula 12 - Turma A: Dominando o Layout e Box Model

(Terça-feira, 11/08/2026 | 14h15 às 16h00)

Nessa aula do dia 11 de agosto, o instrutor Victor explorou os conceitos fundamentais de box model, explicando como as dimensões e espaçamentos definem a estrutura e o comportamento dos elementos em uma página web. Para ilustrar essa organização na prática, foram analisadas as divisões do site do YouTube, demonstrando como grandes plataformas utilizam a estruturação e o CSS para organizar seus componentes visuais. Com o objetivo de fixar os aprendizados sobre posicionamento de forma dinâmica, os alunos jogaram Flexbox Froggy, um desafio interativo que permite aplicar as propriedades de alinhamento do CSS de maneira lúdica, integrando a teoria à prática e facilitando a compreensão da arquitetura de um site.
