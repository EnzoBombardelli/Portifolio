Aula 13 - Turma A: Introdução ao HTML, CSS e JavaScript

(Segunda-feira, 01/06/2026 | 14h15 às 15h45)

Nessa aula do dia 01 de junho, o instrutor Victor deu início aos conteúdos relacionados ao HTML, ao CSS e ao JavaScript, ele começou a aula dando exemplos e analogias para os alunos entenderem o que cada um deles faz, por exemplo: HTML = esqueleto(estrutura), CSS = maquiagem(estilo) e JavaScript = músculos(comportamento). Após isso, o intrutor pediu para a sala escolher um tema para criarem um site, com a finalidade dos alunos começarem a aprender o HTML e o CSS na prática, em conjunto, a sala decidiu que o tema do site que cada um iria fazer seria "Neymar JR". Com isso os alunos começaram a desenvolver seus projetos, como proposto pelo intrutor eles tinham que desenvolver uma biografia sobre o craque.
