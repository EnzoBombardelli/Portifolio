Aula 21 - Turma A: Aprimoramento de Layouts com Flexbox

(Segunda-feira, 24/08/2026 | 14h15 às 15h45)

Nessa aula do dia 24 de agosto, o instrutor apresentou um resumo sobre Flexbox, reforçando os conceitos essenciais para o posicionamento e a distribuição de elementos em uma interface web. Com o objetivo de transformar a teoria em código e consolidar os aprendizados, os alunos foram desafiados a complementar o site dos cards, refinando a estrutura visual e a organização dos componentes iniciada em aulas anteriores. Para encerrar o encontro de forma dinâmica e fixar os conteúdos técnicos, a turma participou de uma partida de Blooket sobre Flexbox, utilizando o formato de jogo para revisar as propriedades de layout de maneira interativa.
