Aula 9 - Turma A: Ensino do HTML semântico.

(Terça-feira, 23/06/2026 | 14h15 às 16h00)

Nessa aula do 23 de junho, o instrutor Victor iniciou conferindo os repositórios dos alunos no GitHub e ensinou como hospedar os sites através do GitHub Pages. Na sequência, foram apresentados conceitos sobre atributos de tags HTML (como id, class e target) e a importância do uso de HTML semântico, utilizando elementos como <header>, <main> e <footer> para garantir uma melhor organização e manutenção do código. Para colocar a teoria em prática, os alunos utilizaram o Visual Studio Code para editar seus projetos, aplicando IDs, classes e menus de navegação em suas páginas. A aula contou com auxílio individualizado para aqueles que apresentaram dificuldades com comandos básicos do computador, enquanto os alunos mais avançados demonstraram autonomia e um progresso significativo no aprendizado de desenvolvimento web.
